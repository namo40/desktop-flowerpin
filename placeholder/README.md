# 대체 그림 팩

`flowerpin.dfpk`는 진짜 그림 대신 쓰는 대체 그림 팩입니다.

- 꽃핀 그림은 이 저장소에 없습니다(`LICENSE-ASSETS.md`). 이 저장소만 받아 빌드하면 이 팩이 들어가고, 꽃핀 대신 눈이 둘 달린 둥근 기둥이 나옵니다.
- 그림은 코드로 그린 도형입니다. 동작 이름, 장 수, 장마다의 시간, 발 자리만 진짜 그림과 같습니다.
- 개발 키(`dfp_pack::DEV_KEY`, 공개된 키)로 암호화되어 있고 "대체 그림" 표시가 달려 있습니다. 공식 빌드는 이 팩이나 개발 키로는 만들어지지 않습니다.
- 이 폴더에는 대체 그림 팩만 둘 수 있습니다. `cargo test`가 확인합니다.
